My backend is essentially a football manager app. it can have multiple users that can create an account and look at players, teams, coaches of particular teams, the stadium a team plays in, the division a team is in. They can favorite players they like and that player is attatched to the user_id. multiple users can favorite the same player. this database is a smaller version of fantasy football manager. In fantasy football each user can pick a player they want on there team that player has information about the team they are on, coach, position, etc. In this case i needed a many to many relationship so users having favorite players was the solution. Super admins have full control to do anything in the database. Users only have the ability to run any GET functions besides seeing other users. They can see any information they would like but are prohibited from POST, UPDATE, and DELETE functions.
